# 墨 SUMI — a quiet kanji study room

> A quiet, paper-textured study room for JLPT kanji — flashcards, quizzes,
> and brush-style writing practice in a single HTML file.

🔗 **Live site:** https://nikhiltomar2712.github.io/sumi-JP-dork/

---

## ✨ Features

### 📖 Flashcards
- Large practice cell with vermilion guide lines
- Ink-reveal animation for each kanji
- Tap-to-reveal fields: readings, radicals, mnemonics, example words
- Hand-written mnemonics for every kanji

### ❓ Quiz
- Multiple-choice, both directions (JP → EN, EN → JP)
- Instant 〇 / ✕ marking with a stamp animation
- Full card reveal after each answer

### 🖌 Writing practice
- Trace kanji on a nine-cell practice grid with ghost glyph
- Classic stroke-order principles listed alongside
- Undo and clear tools

### 📊 Session tracking
- Live progress sheet (ink = correct, vermilion = missed)
- Running tally of marks
- End-of-session score with a review list of missed kanji

### 🎛 Deck options
- Filter by JLPT level (N5 / N4 / N3)
- Sequential or shuffled order
- Custom decks — type any kanji you want to drill
